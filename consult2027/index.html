项目背景

本项目的前身是香港中文大学统计与数据科学系的 Stats4RPgs。该项目通过两期教学发展资助，训练统计学研究生为没有统计背景的研究生设计并主持动手工作坊，其后纳入大学 Improving Postgraduate Learning 计划。

Stats4RPgs Workshop Demo 1 Workshop Demo 2

本年度，项目推广至香港中文大学（深圳），由曾家炜教授负责本土化与实施。与香港原项目最大的区别，是加入统计咨询。统计咨询在其他高校早已推行，例如斯坦福大学与香港中文大学。

Stanford Statistical Consulting CUHK Statistical Consulting

我们由学生主导的工作坊，也不会用来讲授一套统计方法。工作坊将围绕咨询中反复出现的常见问题进行讲解，让因时间或其他原因未能参加咨询的同学，同样可以从这些工作坊中得到帮助。

担任顾问的收获

顾问不会代替同学完成分析。具体津贴标准将在项目经费获批后公布。

  1. 按时薪发放津贴，时间弹性 在项目启动后按实际值班时数发放；可选择每节咨询的前一小时、后一小时或两小时都值班。
  2. 可以丰富履历 面向不同专业同学解释统计与 AI 辅助分析，是不同于一般助教 tutorial 的教学经历。
  3. 接触更多统计应用场景 来访者的问题和数据背景各不相同，能看到统计方法在课程、毕业设计和科研中的真实用法。
  4. 增强沟通技巧和自信 与预先备好答案的 tutorial 不同：你往往不知道对方学过多少统计，也不知道下一问是什么。这种开放式交流，正是锻炼表达与自信的地方。
  5. Vibe Coding 培训 潜在顾问将参加 Vibe Coding 工作坊。讲义提供中文版与英文版。 中文讲义 English notes
